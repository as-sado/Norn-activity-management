Since this is a Python application, you'll need Python 3.13 or later. First, you need to add the path to `pip` to your PATH environment variable
```bash
# Add local ‘pip’ to PATH:
# (In your .bashrc, .zshrc, etc.)
export PATH="${PATH}:${HOME}/.local/bin/
```
Now you can clone the repository and download the application using the script 

```bash
git clone https://github.com/as-sado/Norn-activity-management
cd Norn-activity-management
bash install.sh
```
You can also uninstall it using the uninstall.sh file
